# AD7606 电压采集上位机

一个基于 .NET 8 和 Windows Forms 的 Windows 桌面程序，用于通过串口读取 AD7606 的 8 路 ADC 数据。

## 功能

- 选择串口与波特率，默认 115200，支持连接和断开。
- 读取全部 8 个通道，或选择一个通道单独读取。
- 连接后默认每 1.5 秒自动读取全部通道；也可点击按钮立即读取。
- 每个通道显示 16 位原始十六进制值、有符号十进制值和换算电压。
- 可选 ±5 V 或 ±10 V 量程。
- 缓冲读取串口数据，直到收到本次请求所需的全部字节；1.5 秒内未收齐会报告超时。

## 协议约定

发送 4 字节命令：

| 字节 | 含义 |
|---|---|
| `AA` | 命令头 |
| `01` | 读取命令 |
| `START` | 起始通道，0 到 7 |
| `COUNT` | 通道数量，1 到 8 |

例如读全部通道：`AA 01 00 08`。读通道 1：`AA 01 00 01`；读通道 8：`AA 01 07 01`。

回复按通道顺序连续返回，每个通道 2 字节，**高字节在前**，不带额外帧头。例如全部通道共 16 字节。程序将两个字节组合成 16 位二进制补码有符号数 `s`，再按下式换算：

- ±5 V：`电压 = s × 5 / 32768`
- ±10 V：`电压 = s × 10 / 32768`

## 运行

1. 安装 .NET 8 SDK（开发/构建）或 .NET 8 Desktop Runtime（运行已构建程序）。
2. 将 AD7606 控制板接入电脑，确认设备的串口参数为 8 数据位、无校验、1 停止位（8N1），无硬件流控。
3. 在此项目目录打开终端，执行：

   ```powershell
   dotnet run
   ```

4. 在窗口选择设备串口，保持波特率为 115200 后点击“连接”。

发布 Windows 单文件程序：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

生成文件位于 `bin\Release\net8.0-windows\win-x64\publish\`。

## 与设备固件对接前需确认

当前实现按用户给出的 `AA 01 START COUNT` 和 `COUNT × 2` 字节回复工作，并假定每个样本为**高字节先发的 16 位二进制补码**。若固件实际采用低字节先发、偏移二进制、不同起始通道编号、回复带校验字节/帧头，或 ±5 V/±10 V 量程与 ADC 满量程定义不同，需要按固件协议调整解析和电压换算。串口数据没有响应帧头时，程序在发送前清空接收缓冲，并只接收预期长度；这符合当前描述的定长应答协议。
